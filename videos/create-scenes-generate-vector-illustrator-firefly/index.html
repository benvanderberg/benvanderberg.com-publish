Create scenes using Generate Vector in Adobe Illustrator with Firefly

August 12, 2024

How to use the Generate Vector feature in Adobe Illustrator with Firefly to build full scenes from text prompts.

A walkthrough of Illustrator’s Generate Vector feature powered by Adobe Firefly, showing how to create complete scenes using AI-generated vector artwork. The video covers prompting for scene composition, adjusting results, and integrating generated vectors into an existing Illustrator document. This workflow allows designers to rapidly prototype scene-based illustrations without starting from scratch.
